# Invictus Cockpits Documentation

Guides and reference material for Invictus Cockpit Systems software and hardware.

## Software

<div class="grid cards" markdown>

- **[AIM Cockpit Manager](cockpit-manager/user-guide/index.md)**

    ---

    The Windows app that ties your AIM cockpit network together: board setup, pin assignment, sim integration for DCS World and Falcon BMS, displays, and over-the-air updates.

- **[HOTAS Configurator](hotas-configurator/user-guide/index.md)**

    ---

    The configuration utility for Invictus HOTAS and flight control products: firmware flashing, axis calibration and tuning, and button mapping.

- **[AIM Joystick Probe](joystick-probe/user-guide/index.md)**

    ---

    A modern joystick tester for Windows that shows a controller's complete button map, including all 128 buttons of an AIM Ghost Joystick.

</div>
