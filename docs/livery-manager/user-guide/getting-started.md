# Getting Started

## Requirements

- Windows 10 or 11
- DCS World (standalone or Steam)
- [7-Zip](https://www.7-zip.org/) (free) if you install liveries packed as
  `.7z` or `.rar`; plain `.zip` needs nothing extra

## Download

Grab the latest **Invictus-Livery-Manager-Setup.exe** from the
[Releases page](https://github.com/invictuscockpits/invictus-livery-manager-releases/releases).

## Install

Double-click the installer and follow the wizard. It's signed by Invictus
Machine LLC, so Windows won't flag it as coming from an unknown publisher, and
it installs **just for you**, with no administrator rights needed. The manager
never needs elevation to run either, because it only ever writes into your own
Saved Games folder.

## First launch

When the manager opens it looks for your DCS folder automatically. The pill in
the top-right corner tells you how that went:

- **DCS FOLDER LOCATED** (green): you're ready. Liveries will install into
  the folder shown on the Settings page.
- **DCS NOT FOUND** (yellow): either DCS has never been launched on this PC
  (launch it once so it creates its Saved Games folder, then hit **Rescan** in
  Settings) or your Saved Games lives somewhere unusual. Click the pill and
  pick the folder yourself; see [Settings](settings.md).

That's the whole setup. Head to [Install a Livery](install-a-livery.md) to put
it to work.
