# Invictus HOTAS Configurator Wiki

Welcome to the Invictus HOTAS Configurator Wiki.  
This software is the official configuration utility for all Invictus Cockpit Systems HOTAS and flight control products.

The Configurator allows you to:

* Flash new firmware onto Invictus devices
* Calibrate and tune axes
* Map physical buttons to logical functions
* Select your board, grip, and simulator with simple dropdowns
* Adjust force values between authentic F-16 FLCS representation and more comfortable sim values
* Enable advanced and developer-only features

---

## Getting Started

📥 [Download the latest release](https://invictuscockpits.com/pages/software)

* Install the Configurator
* Plug in your Invictus HOTAS device via USB
* The Configurator will automatically read the current settings on startup

---

## Notes

- **Firmware requirement**: Invictus HOTAS Configurator requires firmware **v2.4.2.0 or later**.  
- Firmware updates are flashed directly from the Configurator — no separate tools are needed in most cases.  
- The Configurator is designed specifically for Invictus hardware. It is **not** a general-purpose joystick builder tool.  
- For open-source firmware reference, see the [FreeJoy project](https://github.com/FreeJoy-Team/FreeJoy).
